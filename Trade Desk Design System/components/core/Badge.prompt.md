Small outlined status chip — never solid-filled. Use for inline status: BREACH, DLL HIT, 0DTE, ER, news tags.

```jsx
<Badge tone="bearish">BREACH</Badge>
<Badge tone="warning">ER</Badge>
<Badge tone="cyan">0DTE</Badge>
<Badge tone="muted">MACRO</Badge>
```

Tones: `bearish` (error/breach), `warning` (advisory), `amber` (active), `bullish`, `cyan` (neutral/event), `muted`. 16px tall, uppercase, 2px radius.
